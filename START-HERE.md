# 4D Agent Office — Netlify setup

This package turns the animated office into a password-protected workspace for real OpenAI API assignments. It is a separate Netlify edition; it does not update or move your existing ChatGPT-hosted preview.

## What is included

- Six specialized agents: Business Development, Software Engineering, XR Training, Volumetric Production, Marketing, and Operations & Finance.
- Actual OpenAI text generation, with optional public web search and clickable sources.
- Saved company knowledge, assignments, outputs, token usage and activity logs.
- Background work that continues after a browser tab closes, once Netlify accepts the worker invocation.
- Office animations driven by task state, not sample numbers.
- A review queue, acceptance tracking, and downloads of results and work history.
- Password login usable on a phone, tablet or computer. This is a single-owner office, not a multi-user employee portal.

These agents research and draft. They do not yet send emails, operate a CRM, purchase anything, execute code, render video, run capture equipment, or build/test a Unity project. Accept draft only records your acceptance. No external action is attached to that button. Agents run the assignments you submit; there is no recurring schedule or autonomous department-to-department delegation in this release.

## 1. Prepare your OpenAI API account

1. Open [OpenAI Platform](https://platform.openai.com/) and sign in. You can use the same account identity you use for ChatGPT.
2. Create/select an API project for 4D Fun Agent Office.
3. Open the platform's Billing page and enable API billing or add credits as required by your account. This app uses paid API usage, not chat messages from your ChatGPT subscription.
4. Open [API keys](https://platform.openai.com/api-keys) in that project and create a secret key. The key needs permission to create Responses.
5. Keep the key in your password manager until you enter it directly into Netlify's environment variables. Do not send it in chat, put it in an assignment, commit it to GitHub, or place it in public/app.js.

Official references: [OpenAI quickstart](https://developers.openai.com/api/docs/quickstart), [API key and production guidance](https://developers.openai.com/api/docs/guides/production-best-practices).

## 2. Put the package on GitHub

Use a NEW private repository, for example `4d-agent-office`. Unzip the package and upload the CONTENTS of the `4D-Agent-Office-Netlify` folder into the repository root. The root must contain `netlify.toml`, `package.json`, `package-lock.json`, `public`, `lib`, and `netlify`.

Do not upload only the `public` folder. The server functions are necessary to sign in, save work, and call OpenAI. No real credentials are supplied in this package. `.env.example` contains blank placeholders only; do not replace it with your secrets in GitHub.

## 3. Create the Netlify project

1. In Netlify, choose Add new project / Import an existing project, then choose GitHub and the repository you created.
2. Keep the base directory blank if you uploaded the contents into the repository root.
3. Use build command `npm run build` and publish directory `public`. The included `netlify.toml` configures these plus `netlify/functions`.
4. Before running assignments, add the settings below in Project configuration → Environment variables. Enable the Functions scope and Production context if Netlify offers scope/context controls. Otherwise use the default all-scopes option. Avoid granting production secrets to untrusted deploy previews.

| Variable | Value you supply |
| --- | --- |
| `OPENAI_API_KEY` | The secret project API key from step 1. |
| `OFFICE_PASSWORD` | A new strong password/passphrase of at least 16 characters. This is what you type to enter your office, not your OpenAI password. |
| `SESSION_SECRET` | A different random secret of at least 32 characters, preferably 64, generated by a password manager. It signs your login session and internal worker requests. You never type it into the dashboard. |
| `OPENAI_MODEL` | Optional. Defaults to `gpt-4.1-mini`. If your project does not have this model, choose a Responses-compatible model your project can access. Web search also requires tool support. |
| `MAX_RUNS_PER_DAY` | Optional. Defaults to `20`; set `5` for a small first test. Maximum configurable value is 200. This is an assignment-count limit, not a dollar limit. |

Netlify supplies the site URL and Blobs credentials automatically. You do not need Supabase, database SQL, a Netlify personal access token, or a permanently running computer.

5. Deploy. After later environment-variable changes, deploy again so Functions use the new settings.
6. Open the production HTTPS URL shown by Netlify. Your office is available there from any device with internet access while the service/account is active. You can connect a custom domain later in Netlify's Domain management.
7. Sign in using `OFFICE_PASSWORD`. The session lasts eight hours. Changing the password or signing secret and redeploying invalidates old sessions.

This package's supported installation is a Git-based deployment or the CLI method below. A basic static drag-and-drop of `public` will not install the backend. See [Netlify deployment options](https://docs.netlify.com/deploy/create-deploys/).

## 4. Run your first real assignment

1. Open Connections. Confirm the API key is configured and storage is connected. “Configured” detects presence of the key; a successful run verifies actual API access.
2. Open The Brain. Add your confirmed company capabilities, service descriptions, pricing if desired, target customers and brand voice. Save. Your ChatGPT history is not automatically transferred.
3. Click Assign work. Choose Marketing. Leave public web research OFF for a simple first test.
4. Enter: “Write a 150-word introduction to 4D Fun's workflow solutions, virtual training simulations, and volumetric capture services. Do not invent customers or results.”
5. Click Run assignment. This authorizes one paid API request. Watch the queue move from Queued to Running to Review.
6. Open the assignment to read its output, activity and token usage. Click Download result or Accept draft.
7. For a web research test, choose Business Development and enable public web research. Ask: “Find five US manufacturing companies whose publicly documented training needs could fit custom VR safety training. Cite sources, explain each fit, and draft outreach for review. Do not invent emails.”

The office polls every ten seconds while open. The background function saves the result even if you close the page, then the result appears when you sign back in. Once a task is submitted, you cannot cancel the paid call in this version.

## 5. Limits and costs

Each assignment uses a maximum of 3,500 output tokens and up to three web-search tool calls when enabled. Input includes your company context and assignment. OpenAI usage and Netlify hosting/functions/storage are billed by their respective services. The UI shows token usage when OpenAI returns it, not a calculated dollar total. Search can add separate charges. Failed or interrupted calls can still incur usage.

The package allows at most three active recent assignments, 20 new assignments per UTC day by default, and 500 saved assignments. The run count includes failed or queued assignments; resuming an existing queued assignment does not increment it. Counts and updates use conditional storage writes so concurrent requests cannot bypass the limit or overwrite each other's state.

After 500 assignments, export the work history and extend the storage implementation before adding more. Existing history is never silently deleted. Keep the JSON export as a readable backup; an import/restore screen is not included.

Each worker allows approximately 11 minutes for the OpenAI request within Netlify's 15-minute background limit. Long research should be split into smaller assignments. This is not an always-running virtual employee or a full autonomous company yet. [Netlify background-function documentation](https://docs.netlify.com/build/functions/background-functions/) describes availability and platform execution limits.

## Troubleshooting

| What you see | What to do |
| --- | --- |
| Setup needed on the login page | Add missing variables, check their required lengths, and redeploy. |
| Backend unavailable / HTML instead of JSON | Confirm the whole repository was deployed, not only `public`. In Netlify Functions, confirm `office` and `agent-background` exist. |
| Cannot sign in | Use OFFICE_PASSWORD, not your OpenAI login. Six attempts per IP per minute are allowed; wait one minute after a limit message. |
| API key configured but run fails | Read the error in the saved assignment. Check OpenAI billing, key permissions, model access and quota. |
| Queued for more than a minute | Open the task and click Resume queued. A conditional claim prevents two workers from running the same paid assignment. Check `agent-background` logs if it remains queued. |
| Running but no completion after 14 minutes | The UI marks the run Interrupted / unconfirmed. Inspect the Netlify function logs. The package does not automatically repeat paid requests after an uncertain failure. Use New run from this task only if you want a new paid attempt. |
| Web search rejected | Check that OPENAI_MODEL supports Responses web search. Test a text-only assignment first. |
| Netlify storage unavailable | Confirm Blobs and Functions are available for this project and that the deployment succeeded. The app fails closed rather than using unsaved local state. |
| Login works on production, not local files | This is a server-backed package. Opening index.html directly cannot run the backend; use the deployed production URL. |

## Optional terminal deployment

Use this only if you prefer terminal commands over importing from GitHub. Install Node.js 22 or later, open a terminal in the extracted folder, then run:

```sh
npm ci
npx netlify-cli login
npx netlify-cli init
```

Select/create your intended Netlify project. Add the three required variables through the Netlify web dashboard, then deploy the entire package:

```sh
npx netlify-cli deploy --build --prod
```

Do not pass your OpenAI key as a terminal command argument. Do not use an anonymous deployment for your company office.

## Validation performed for this delivery

Automated local checks cover session signature validation, expiry and password rotation; same-origin protection; idempotent submission; run limits; conflicting storage writes; duplicate background dispatch; API quota failure; incomplete responses; and safe citation links. Mock responses were used for worker tests. Frontend and function JavaScript syntax was checked.

No live OpenAI call or Netlify account deployment was performed in this environment. Your first deployed assignment is the final integration check. No API key is embedded in the package.

Technical references: [Responses web search](https://developers.openai.com/api/docs/guides/tools-web-search), [Netlify Blobs](https://docs.netlify.com/build/data-and-storage/netlify-blobs/).
